# I 阶段：仪器落成（Instrument Commissioning）

> 通用协议，不含任何领域内容。领域数值与约定由 `domain-packs/<领域>/` 提供。
> 一句话：**在拿一台新工具的数字去支撑结论之前，先证明这台工具在我要用的范围内是可信的；证明不了就缩小它的可信范围，而不是假装可信。**

## 为什么必须有这个阶段

自产数值和研究结论之间隔着一台仪器。仪器没验过时，两类错误在产出上完全同形：

- 工具错了（约定反了、单位错了、边界不对、判读偏了）；
- 真有发现（模型给出的现象确实是新的）。

事后无法区分。所以验收必须在**研究性算例之前**完成，而且验收的目的是把"错在哪一层"变成可分类的——不是证明工具永远正确。

## 阶段总览

```
I0 定标        说清这台仪器测什么、精度要多少、什么算成功
I1 单点校准    物理常数 / 材料常数逐项对拍（预注册容差）
I2 自洽自检    不依赖文献的恒等式、往返重构、约定审计
I3 复现        复现一篇已发表结果（定性为主，定量带误差带）
────────────── 门：I1–I3 达成 → 出具仪器卡，声明覆盖范围 ──────────────
I4 筛查        在假设认为重要的自由度上跑矩阵（含对照条件）
I5 诊断分流    误差结构分解 → 四类标签 → 各自去处
```

I1–I3 是**仪器自己的**验收；I4–I5 是**仪器与理论的关系**的验收。前者决定"能不能用"，后者决定"能信到什么程度、缺什么"。

---

## I0 定标

产出：仪器规格（写进仪器卡顶部）。

必须回答，缺一不可：

| 项 | 内容 |
|---|---|
| 仪器名 | 稳定 ID（`<领域>-<方法>-v<版本>`），后续所有数值都挂它 |
| 测量对象 | 这台仪器**测什么量**（不是"它能算什么"） |
| 精度目标 | 该量的可接受误差，**先于任何计算写下** |
| 输入 | 它依赖哪些外部输入（模型、参数、参考数据） |
| 可调设置 | 哪些设置会改变结果（超胞、边界、收敛阈值、种子…） |
| 覆盖范围 | 声明打算在哪些体系/条件下使用 |
| 成功判据 | 什么情况下算"这台仪器在我声明的范围内可用" |

**反模式**：不写精度目标就开始算。没有目标，"偏差 15%"这句话没有意义。

---

## I1 单点校准（对拍→参考值）

逐项对拍**可以直接与外部参考比较的量**：物理常数、材料常数、标准数据。

对每一项，先登记三件事再跑：**参考值 / 出处 / 容差**。跑完只填"实测"和"判定"，参考值与容差不得事后修改。

| 量 | 参考值 | 出处 | 容差 | 实测 | 判定 |
|---|---|---|---|---|---|

判定三态：**通过 / 超出容差 / 参考不可得**。

> "参考不可得"是合法结论（论文付费墙、数据未公开、标准缺失）。它不等于失败，但必须导致**覆盖范围收缩**（见"门的判法"）。

---

## I2 自洽自检（不依赖文献）

这一层最容易被跳过，但它抓的错误最致命——因为它抓的是**约定错**，而约定错会被 I1 部分吸收（常数对得上、场反了）。

必做三类：

**① 恒等式 / 守恒量**。仪器输出应满足的解析关系。例：能量守恒、对称性、归一化、互易关系、平衡态残差。

**② 往返重构（round-trip）**。把仪器输出的量反解回输入参数，看能否还原。
> 这是抓"约定反了"最有效的手段：正向算出来看着对，反向拟合回去就会露馅。任何依赖坐标、符号、方向、相位、时基的量，都必须做这一次往返。

**③ 约定审计**。列一张表，把每一处"可能定反"的东西写出来并指定验证方式：

| 约定项 | 本仪器采用 | 与参考实现是否一致 | 验证方式 |
|---|---|---|---|
| 坐标轴 / 取向 | | | |
| 符号（拉压、正负） | | | |
| 单位制 | | | |
| 时间基准 / 相位 | | | |
| 索引与编码 | | | |
| 文件与路径（非 ASCII、编码） | | | |

**环境地板**也算约定审计的一部分：路径编码、非 ASCII 目录、时区、浮点精度、库版本。它们不是细节，会静默污染全部数值。

---

## I3 复现（已发表结果的再现）

挑 **1–3 个**已发表结果复现，优先选：

- 有明确定量值或明确定性判据的；
- 该领域的标准验证案例（教科书写着"这个应该这样"的）；
- 换一个体系就能重跑、不依赖原作者私有数据的。

判定：
- **定量**：落在原文误差带内 → 通过；
- **定性**：方向、排序、有无某个现象一致 → 通过（定性通过不得被表述为定量一致）；
- **参考不可得** → 覆盖范围收缩，并在仪器卡里写明"该项未验证"。

**反模式**：只复现最容易的一项就宣布仪器可信；或把"定性方向对"写成"与实验一致"。

---

## 门的判法：覆盖范围收缩

I1–I3 不必全绿。合法出口有两个：

1. **全过** → 仪器卡记 `已落成`，覆盖范围 = 声明范围。
2. **部分过** → 仪器卡记 `部分落成`，**覆盖范围精确收缩到已通过的部分**；未通过的项写进"已知缺陷"，并注明"该类数值只能标探索性"。

不允许的第三种出口：把没通过的项从验收表里删掉，然后按全过使用。

仪器卡必须有一节**"允许支撑什么 / 不允许支撑什么"**，用可检查的措辞写，例如：
- ✅ 可用于：`<体系A>` 在 `<设置X>` 下的 `<量Q>`
- ⛔ 不可用于：`<体系B>`；或任何跨 `<设置Y>` 的外推

## I4 筛查矩阵

目的**不是**确认假设，是**暴露仪器与理论在哪里不一致**。

设计要点：

| 要素 | 要求 |
|---|---|
| 自由度 | 覆盖假设认为重要的那几个轴（不是能跑的都跑） |
| 对照条件 | 必须至少一个**已知会给出某种结果**的对照，用来校准判读 |
| 分辨率 | 步长要细到能区分"没发生"和"差一点就发生" |
| 停机规则 | 首次事件后继续走几步（防止把"刚发生"当成"临界"） |
| 未知条件 | 至少保留一格"不知道会怎样"的，防止矩阵被先验填满 |

产出 `筛查矩阵.md`：每行一个算例，列 = 条件 + 预测 + 实测 + 是否一致。

---

## I5 误差结构诊断与分流

**这一步是 I 阶段的核心价值，也是最常被省略的一步。**

### 第一步：不许只报一致率

先做三件事：

1. **一致率**：多少算例预测与实测一致（这是最没信息量的数字）。
2. **误差方向**：按"预测的类别"分组，看误判是集中还是分散。
3. **零模型比较**：如果全部猜同一类，一致率是多少？预测率没有显著超过零模型，说明判据在这个范围内无信息。

> 判据：若误差在某一类上**单向**集中（例如"预测发射、实际全部解理"），说明这不是随机误差，而是某个系统性缺项。随机分散的误差才更像噪声。

### 第二步：检验是否可用常数修正

试一个全局修正因子，看一致率能提升多少。

- 提升显著 → 存在可参数化的系统偏差（记录下来，但不要急着当结论）；
- 提升很小 → 偏差**不是常数能吸收的**，说明缺的是结构性项（某个物理机制、某个输入量本身不对）。这是更强的结论。

### 第三步：四分法分流（每个偏差必须有且只有一个标签）

| 标签 | 判据 | 去处 | 谁负责改 |
|---|---|---|---|
| **仪器缺陷** `instrument-defect` | 已知答案不过 / 约定错 / 数值 bug / 边界与物理不符 | 修仪器 → 重跑受影响算例 → 受污染结论作废重出 | 核心 + 领域包 |
| **领域输入** `domain-input` | 仪器自检通过，但判据用的输入量不代表真实对象（参数不准、模型过简、参考数据有偏） | **交领域包升级**，不动仪器 | 领域包 |
| **理论缺口** `theory-gap` | 仪器与输入都可信，判据本身缺项（少一个机制、少一个耦合） | **变成研究假设的证据**，进选题卡 | 研究侧 |
| **存疑** `open` | 缺文献、缺算力、缺权限，当前无法判定 | 登记编号 + 原因 + **解除条件** | 挂起 |

**这条分流线就是"通用"与"领域"的分界**：`instrument-defect` 里凡属"换个领域就不成立"的部分（判读阈值、事件定义、算例清单）一律落领域包；核心只保留"缺陷分类学"和"分流流程"。

### 第四步：写出可交割的诊断

每条诊断必须落到一句可执行的话：

```
<偏差现象> | 标签 | 证据（算例编号/数值） | 归属（核心/领域包/研究侧） | 下一步动作 | 若不解决的后果
```

---

## 阶段出口 DoD

- [ ] 仪器卡存在，含：规格、覆盖范围、允许/不允许支撑什么、已知缺陷
- [ ] I1 表每项都有"判定"，且无一项参照事后修改过容差
- [ ] I2 的约定审计表完整，往返重构已做并记录数值
- [ ] I3 至少一项复现，且标明定量还是定性
- [ ] I4 矩阵有对照条件与停机规则
- [ ] I5 每个偏差都有唯一标签，`open` 项都有解除条件
- [ ] 所有自产数值都能通过"数字出生证"五问

## 阶段内反模式

1. 未落成先跑研究性算例。
2. 后见容差：把结果看着不舒服的项从表里删掉。
3. 只报一致率，不做误差结构与零模型比较。
4. 用常数因子压偏差，不问偏差来源。
5. 把"参考不可得"写成"通过"。
6. 把领域约定问题拿到核心层修。
7. 只用同一套代码验证自己（缺独立重构/解析恒等式）。
8. 单条件宣称普适。
9. 把定性一致表述为定量一致。
10. 仪器卡的"已知缺陷"一栏空着——几乎不可能真的没有。
