# 跨领域元经验

规则：每个领域完成冷启动与 Q1–Q8 后，把"出现了哪些类型的轴、用户假设漏了哪些、
哪些阈值被调过"写成一条，附领域名与日期。**只用它扩展检索词和提醒检查，不作为预设结构参与归纳。**

格式：

```
## <领域>（<日期>）
- 轴类型：
- 用户的假设漏掉了：
- 聚类阈值调到：<值>（原因）
- 归轴阈值调到：<值>（原因）
- 反复出现的坑：
```

---

## weno-示例（合成语料，2026-11-01）

- 轴类型：线性格式谱特性、候选模板、非线性权重、光滑指示器（与用户四轴一致）。
- 用户的假设漏掉了：时间推进、通量分裂与特征投影（需要在真实语料上确认）。
- 聚类阈值调到：0.28（0.30 时四个轴只剩三个，权重与指示器被并在一起）。
- 归轴阈值调到：0.15，余量 0.06（只有 0.06 以上的领先才归轴，否则留未归类池，
  防止"只有一个轴时什么都往里吸"）。
- 反复出现的坑：短词组（<8 词）的词面相似度普遍 <0.2，单靠聚类会把同轴记录拆散；
  抽取时必须让 target_text 写成完整短语（"nonlinear weights that approach the optimal
  linear weights in smooth regions"），而不是两三个词。
