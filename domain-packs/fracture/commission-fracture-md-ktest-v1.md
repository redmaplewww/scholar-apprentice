## I0 规格

| 项 | 内容 |
|---|---|
| 仪器名 | `fracture-md-ktest-v1` |
| 测量对象 | 0 K 准静态下，单一晶体的**裂尖首次事件类型**（解理 / 位错发射 / 孪晶）与**临界应力强度因子 K_c** |

| 成功判据 | I1 通过 + I2 往返误差 ≤2% + I3 至少一项复现 |

**约定审计**：

| 约定项 | 本仪器采用 | 与参考实现一致 | 验证方式 |
|---|---|---|---|
| 裂纹坐标系 | x=扩展、y=裂面法向、z=前沿，y=z×x | 是 | 面法向与叉积断言 |
| 4 指数 → 3 指数 | Miller-Bravais 标准变换 | 是 | 面内方向与面法向正交断言 |
| 弹性常数旋转 | C 张量四阶旋转至裂尖系 | 是 | 与 matscipy 各向异性解一致 |
| 单位 | length=Å, energy=eV, K=GPa·√Å；对外换算 MPa√m | 是 | 与文献值对拍 |
| 张量符号 | LAMMPS 应力取负号转成拉为正 | 是 | 单轴拉伸检查 |
| 裂尖面隔离 | 原子类型/组排除，防止愈合 | 是 | 低 K 下无愈合 |
| 路径编码 | 势文件镜像到 ASCII 目录 `D:/scholar-data/...` | 是 | LAMMPS 打不开非 ASCII 路径（已踩坑） |
| 索引基准 | 0-based numpy ↔ 1-based LAMMPS | 是 | 原子数一致 |

## 覆盖范围（落成后）

**✅ 允许支撑**

- Cu 单晶 (111)[1-10]、0 K、准二维、R=100–150 Å 的**定量 K_c 与 K_Ie**（与 Rice 差 ≤2%，与文献同序）。
- fcc/bcc/hcp 单晶的**材料常数与面能**（来自 T0 子仪器，最稳）。
- hcp 各势、三个基准取向的**事件类型相对比较**（同一势内、同一判读规则下的"脆/韧"排序）。
- 任何体系内**跨势函数的属性分歧**（这是最可靠的产出，因为不依赖绝对精度）。

**⛔ 不允许支撑**

- Al/Ni 的**定量 K_Ie**（D-01 未解，偏差 −15%）。
- 任何**有限温度**、**三维裂纹前缘**、**晶界/孪晶界/孔洞**、**含溶质或氢**的结论（未做）。
- 使用 **ML 势**（LAMMPS 缺 ML-PACE/QUIP/DeePMD）。
- 把**理想 Griffith K_IG 当作实测解理门槛**：实测解理中位高 22%（D-08）。

## 已知缺陷与分流表

| # | 现象 | 标签 | 归属 | 现状 | 影响 |
|---|---|---|---|---|---|
| D-01 | Al/Ni 的 K_sim/K_Ie ≈0.85，低于 Rice 15%，尺寸收敛后不变 | **theory-gap** | 研究侧（RQ2） | 未解；参考全文不可得 | 定量 K_Ie 不可用，定性可用 |
| D-02 | 首次事件判据偏灵敏（DXA 出现 ~5 Å 位错线即判发射） | **instrument-defect** | 领域包（事件定义） | **暂不修**（领域强相关，改在包里） | 临界 K 可能偏低；机制**方向**不受影响 |
| D-03 | 每个裂纹面只取了一个前沿方向 | **domain-input**（覆盖不足） | 领域包（算例清单） | 待补 | 台阶几何依赖前沿，覆盖范围收缩 |
| D-04 | 只有 0 K、准二维、单晶 | **domain-input**（覆盖不足） | 领域包 | 待补三维校核 | 已在"不允许支撑"中声明 |
| D-05 | fcc 孪晶判据误报（用 c 轴偏转判 fcc） | **instrument-defect** | 核心（判读规则是否适用） | 已停用 fcc 孪晶检测 | 已消除 |
| D-06 | K_IE 使用直路径 γ_us，未含 shuffle 与法向应力 | **domain-input** | 领域包（判据输入升级 → RQ1/RQ2） | 未做 | 这是 H1′/H2′ 的入口 |
| D-07 | Mg 锥面 I 在 4 势中 2 脆 2 韧 | **theory-gap** | 研究侧（RQ3 机制相图） | 待扩展矩阵 | 直接支撑 H3′ |
